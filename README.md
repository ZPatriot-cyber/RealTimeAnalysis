# RealTimeAnalysis
# ⏱️ Анализатор систем реального времени

> Практическая работа № 1 по курсу «Системы реального времени» (СРВ)  
> Классификация задач по жёсткости временных ограничений и расчёт их выполнимости


## 🩺 О проекте

Представьте медицинский монитор у постели пациента. Он одновременно следит
за сердечным ритмом, проверяет пороги тревоги, обновляет экран и пишет
данные в архив. У каждой из этих задач — свой запас времени на реакцию.
Опоздать с тревогой нельзя. Опоздать с обновлением экрана — не страшно.

Эта программа помогает ответить на главный вопрос инженера систем реального
времени: **успеет ли система вовремя**?

Она берёт список задач, считает для каждой запас времени, находит самое
«узкое место» системы и проверяет, не перегружен ли процессор в принципе.

**Вариант:** медицинский монитор — контроль сердечного ритма, тревога по
порогу, обновление экрана, запись в архив.

---

## ⚙️ Что умеет программа

| Возможность | Описание |
|---|---|
| 🏷️ Классификация задач | жёсткое / твёрдое / мягкое реальное время |
| ⏳ Расчёт запаса | `L = D − C` — сколько времени в запасе |
| ✅ Проверка выполнимости | успевает ли задача уложиться в срок |
| 🔍 Тип дедлайна | неявный, ограниченный или произвольный |
| 🚨 Критическая задача | та, что ближе всего к провалу дедлайна |
| ⚡ Требуемое время реакции | `R_треб = min(D)` по жёстким задачам |
| 📊 Коэффициент загрузки | `U = Σ(C / T)` и проверка `U ≤ 1` |
| 🖥️ Архитектурный класс | одно- / много-процессорная / распределённая |

Все входные данные хранятся в файлах `data/tasks.csv` и `data/system.json` —
никаких «магических чисел» в коде. Хотите другой вариант? Меняете файлы, а
не программу.

---

## 🧠 Как это устроено внутри

1. **Загрузка.** Программа читает список задач из CSV и параметры системы
   из JSON.
2. **Анализ задач.** Для каждой задачи считается запас, проверяется
   выполнимость дедлайна и определяется его тип.
3. **Анализ системы.** На основе всех задач вычисляется класс системы,
   находится критическая задача, требуемое время реакции и загрузка
   процессора.
4. **Вывод.** В консоль печатается аккуратная таблица и текстовое
   заключение с выводами.

Код разделён на независимые части: отдельно чтение данных, отдельно формулы,
отдельно вывод. Поменять формат входных файлов можно, не трогая расчёты — и
наоборот.

## 🚀 Запуск

### Вариант A — Visual Studio

1. Откройте `RealTimeAnalysis.csproj`.
2. Проверьте, что `data/tasks.csv` и `data/system.json` копируются в
   выходной каталог (**Свойства файла → Копировать, если новее**).
3. Нажмите **F5**.

### Вариант B — командная строка

```bash
dotnet run --project RealTimeAnalysis
```
